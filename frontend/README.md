# Фронтенд — оценка шансов поступления

Простое SPA (React + TypeScript + Vite + Recharts) для оценки шансов
поступления по спарсенным конкурсным спискам.

## Что делает

- Фильтр по **вузу** и **направлению** (данные из последнего успешного снимка).
- Мультивыбор **приоритетов** — гистограмма пересчитывается по выбранным
  (пусто = все приоритеты).
- Фильтр по **согласию на зачисление**: все / только с согласием / только без.
  Режим «с согласием» показывает срез тех, кто реально претендует на место
  в текущей волне, — средний и проходной балл считаются по этому срезу.
- **Гистограмма распределения баллов** с тремя вертикальными маркерами:
  средний балл (жёлтый), оценочный проходной по числу мест (красный),
  твой балл (зелёный, вводится в поле).
- **Вывод о реалистичности** поступления: насколько балл выше/ниже среднего
  и проходного, твоя позиция в списке.

Заявления без баллов (нет результатов ЕГЭ, ~1/4 списка) в расчётах не
учитываются — иначе они искажают средний балл.

## Запуск

Нужен запущенный backend (FastAPI) на `http://127.0.0.1:8000`.
Dev-сервер проксирует `/api` на него (см. `vite.config.ts`).

```bash
npm install
npm run dev        # http://localhost:5173
```

Прод-сборка:

```bash
npm run build      # dist/
npm run preview
```

## Данные

Ходит на два эндпоинта backend:

- `GET /api/v1/data/universities` — вузы и направления, по которым есть данные.
- `GET /api/v1/data/applicants?university_code=…&major_code=…` — заявления
  одного направления из последнего снимка со статусом `success`.

## Структура

```
src/
├── api.ts                     # клиент backend
├── types.ts                   # типы ответов API
├── hooks/useApplicantData.ts  # загрузка заявлений
├── utils/analysis.ts          # фильтрация, средний/проходной балл, бины
├── components/
│   ├── Filters.tsx            # вуз, направление, приоритеты, согласие, свой балл
│   ├── HistogramChart.tsx     # гистограмма + маркеры (Recharts)
│   └── Summary.tsx            # плитки метрик + текстовый вывод
└── App.tsx                    # сборка экрана и состояние
```

## Важно про проходной балл

«Проходной» — **оценка**: список сортируется по баллу убыв., берётся балл
абитуриента на последнем бюджетном месте. Это упрощение: реальное зачисление
учитывает межнаправленческое перераспределение по приоритетам и согласиям.
