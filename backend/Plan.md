- Страница `https://priem.sut.ru/spisok-abiturientov` — форма с полями general(101=СПбГУТ),
  education_base_to(11=Бакалавриат), training_form(4=Очная, 1=Очно-заочная, 2=Заочная),

- Конкурсные группы грузятся AJAX: `POST /new_site/inc/ajax_abitur_2025.php` тело
  `jsonData={action:"get_spec",...}` -> JSON `{result, selecter:"<option value=id>КОД Очное Бюджет Название</option>..."}`.
- Таблица результатов: `POST /spisok-abiturientov` с полями формы (+ hidden token из HTML,
  action=get_result_new, rekzach=0) -> ВОЗВРАЩАЕТ HTML целой страницы с таблицей `t_<groupid>`.

- Колонки таблицы: №, Уник.ид (ЕПГУ), ид в вузе, Приоритет, БВИ, Общие ИД, Целевые ИД,

## Этап 9. Четвёртый вуз — Самарский политех / СамГТУ (samgtu.ru)

Разведка сайта (проверено):
- Страница `https://samgtu.ru/admission/competetivegroup` — AngularJS-приложение, данные
  грузятся AJAX, URL при клике не меняется. Контроллер `rating.js` вызывает два JSON-API:
  - `GET https://lk.samgtu.ru/publics/competetivegroup/kcps` — список конкурсных групп
    (CompetetiveGroupID, CompetetiveGroupName='код + название', StudyFormName, Representation,
    PlaceTypeID, KCP=мест, ApplicationCount). Уровень бак/спец — d[0]['items'] (~550 групп).

- Оба эндпоинта — обычный GET JSON, без cookie/CSRF. Браузер не нужен (HTTP-клиент Playwright).
- Направление сопоставляем по коду в рантайме: CompetetiveGroupName начинается с кода,
  StudyFormName='Очная', Representation='СамГТУ', PlaceTypeID=1 -> CGID (как у СПбПУ).
- Категории (PlaceTypeID в rating): 1=Основные места КЦП (общий бюджет), 2=Особая квота,
  3=платка, 5=Отдельная квота, 11=Целевая. Парсим ТОЛЬКО PlaceTypeID=1 (как «Общий конкурс»).
- Поля строки: siteName=код, SummaAll=сумма, EGE_sum=ЕГЭ, IndividualAchivment/(SummaAll-SummaResults)=ИД,
  Benefit=льгота, OriginalReceived=согласие, PriorityNumber=приоритет, IsNoExam=БВИ.
